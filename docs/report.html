Groundtruth

Independent facts about the exact home in a listing. The extension reads only the address, and if it can't be sure which home that is, it doesn't guess.

02Method

  1. Address extraction. We read the listing's address heading on REA and Domain, and nothing else. A parser splits it into unit, number, street, suburb and postcode. It handles 902/417-419, C603/, 20E/, 18b/, 188A, Level 8/1 (a floor, not a unit), 330&330A/, Penthouse/, missing street types (4/6A Greenknowe) and typos like Ocean St Street.
  2. The stale-SPA trap. Both portals are single-page apps. When you click from one listing to the next, the URL changes before the heading does, so a naive read pairs the new URL with the old address and shows facts for the wrong home. We wait until the heading matches the new route, re-read on every navigation, and drop any reply for a page we've left. TODO: describe exact mechanism (MutationObserver / URL-change debounce) and how we caught it
  3. Resolver. If the suburb is outside the 29, we return OUT_OF_AREA without calling the API. Otherwise we geocode through Microburbs, score candidates on unit, number, street and suburb separately, and return EXACT only if all four agree. Each reply carries a receipt showing what we read, how we normalised it, and which checks passed.
  4. Unit narrowing. When the street address matches but the unit is withheld or unclear, we return BUILDING and list the units at that number from the supplied address file. The buyer can narrow the list by typing the bedroom count. We only use that number if the buyer typed it; we never read it from the listing.

05Why these facts

We only show facts the portals don't already give, and that a buyer would otherwise pay for or dig up. Quoting accuracy tells you how far to trust the price guide. The AVM and sale history give you an independent anchor for the price. Street vs suburb shows whether this street beats or trails its suburb. The strata levy and risk overlays are costs that only show up after you've committed. We left out facts the portals already show, such as schools and the price guide.

08Held-out check

Before we tuned the resolver, we collected and froze 30 real for-sale listings (15 REA, 15 Domain) at 10:27 AEDT. For each one we recorded only the URL and the displayed address, and labelled it by hand. Expected outcomes: 20 EXACT, 5 BUILDING, 4 OUT_OF_AREA (Bondi, Chatswood, Marrickville, Leichhardt), 1 NO_MATCH (no street number shown). The set covers slash units, letter units, Level n, number ranges, 1A-style suffixes, multi-unit and named units, partial addresses and a locality alias.
